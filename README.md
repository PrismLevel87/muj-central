## 🌟 What is MujCentral?

**MujCentral** is a modern, lightweight, and powerful toolkit designed to bring all your essential utilities into one elegant place. Whether you're a developer, designer, system administrator, or everyday power-user — this repository gives you a curated collection of tools, scripts, and resources that just *work* out of the box.

Built with performance in mind, MujCentral eliminates the clutter of scattered utilities and delivers a seamless, unified experience. No bloat. No distractions. No forced subscriptions. Just pure functionality wrapped in a clean, thoughtfully designed interface.

Over the past two years the project has evolved from a small personal script collection into a fully-fledged modular platform used by thousands of people around the world. Every release is tested, documented, and shaped by real feedback from the community.

## 🚀 Quick Start

Get up and running in under a minute:

```bash
# Clone the repository
git clone https://github.com/your-username/muj-central.git

# Navigate into the folder
cd muj-central

# Install and run
./install.sh && ./start.sh
```

That's it! The app will launch automatically and guide you through a quick setup wizard. On first launch you can pick a preset, connect your preferred modules, and the rest is handled for you.

## 📖 Documentation

Comprehensive documentation is available for every module. Here's a quick overview of the folder structure:

```
muj-central/
├── core/           # Core engine and utilities
├── modules/        # Optional feature modules
├── themes/         # UI themes and skins
├── docs/           # Full documentation
├── presets/        # One-click configuration files
└── scripts/        # Helper scripts and tools
```

Each module includes its own README with usage examples, configuration options, and troubleshooting tips. If you ever get stuck, the `docs/` folder is your best friend — it covers everything from setup quirks to advanced module development.

**Popular modules include:**
- `file-forge` — batch file operations and smart renaming
- `net-pulse` — network diagnostics and latency monitoring
- `clip-vault` — encrypted clipboard history
- `task-weaver` — automation recipes for repetitive work
- `theme-lab` — live theme editor with export/import

## 🧭 How It Works

MujCentral runs on a tiny Rust-powered core with a JavaScript front-end layer. This means startup time is measured in milliseconds, memory usage stays under 40 MB even with a dozen modules active, and the entire app remains fully portable — you can drop it on a USB stick and carry it anywhere.

The modular architecture means each feature lives in its own sandboxed package. Modules communicate through a lightweight event bus, so a misbehaving add-on can never crash the core. Updates are delivered per-module, letting you upgrade individual features without touching the rest of the system.

Configuration is stored in a single human-readable `muj.toml` file — version it in git, share it with teammates, or back it up in seconds.

## 💡 Why Choose MujCentral?

Most toolkits force you to install dozens of packages you'll never use. **MujCentral** flips that philosophy — start with a tiny core, then add only the modules you actually need. The result? A faster, cleaner, and more enjoyable experience.

Thousands of users have already made the switch, and the community keeps growing every day. Whether you're automating workflows, managing files, or building something new — MujCentral has your back. Developers praise the clean API, designers love the theme engine, and sysadmins appreciate the portable, dependency-free packaging.

And unlike many "all-in-one" tools, MujCentral never locks features behind a paywall. Everything in this repository is free, open, and yours to modify.
